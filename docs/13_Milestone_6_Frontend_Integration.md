# Milestone 13: Milestone 6 - Frontend Integration & UI/UX Design

## 1. User Interface Modules & Pages
The React frontend provides a responsive single-page application (SPA) structured into 11 dedicated functional modules:

1. **Overview Dashboard**: System architecture overview, seeded benchmark statistics, and workflow guide.
2. **Dataset Management**: Drag-and-drop file uploader (CSV, JSON, XLSX), automatic profiling dashboard, and dynamic column role assignment (Input, Target, Identifier, Preserved).
3. **Text Preprocessing**: Interactive NLP sandbox demonstrating tokenization, punctuation removal, stopword removal, and domain preservation.
4. **Augmentation Studio**: Multi-algorithm augmentation panel with real-time preview, generation counts, and Google Gemini integration badge.
5. **Semantic Validation**: Inspection table with color-coded pass/fail tags, similarity sliders, and detailed flag explanations.
6. **Dataset Comparison**: Side-by-side distribution comparison before and after data augmentation.
7. **Model Training**: Zero-leakage experiment launcher supporting both classification and regression models.
8. **Evaluation Results**: Comprehensive performance matrix displaying Baseline vs. Augmented Accuracy, Macro F1, Confusion Matrices, and Gain Deltas.
9. **Robustness Testing**: Perturbation stress-testing module evaluating model degradation under noise.
10. **Export Center**: Export datasets in CSV or JSONL format and download academic empirical reports.
11. **Project Documentation**: Interactive in-app technical reference and user guide.
